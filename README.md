## 🌟 Key Features

1. **Interactive Device Frame Previewer**: Test featured projects in simulated Desktop (16:9), Tablet (768px), or Mobile (375px) viewports with real-time reload and live URL navigation without leaving the portfolio.
2. **Anthropic AI Prompt Engineering Lab**: Interactive live case study comparison comparing naive zero-shot prompts with structured Few-Shot / Chain-of-Thought prompts, complete with real-time accuracy, hallucination, and schema validation benchmarks.
3. **GSAP Fluid Motion & Animation**: Staggered scroll reveals and subtle sine-wave floating cards powered by GreenSock Animation Platform (GSAP).
4. **Dynamic Multi-Palette Theme Engine**: Instantly switch between **Cyber Cyan**, **Emerald Mint**, and **Amethyst Neon** with persistent `localStorage` support.
5. **Web Audio Synthesizer**: Subtle tactile UI click/blip audio feedback synthesized directly via the HTML5 Web Audio API (zero external assets or bandwidth overhead, toggleable on/off).
6. **Resume Viewer & Downloader**: Interactive full-page modal with 1-click download of the official `resume.pdf` accompanied by celebratory confetti particles.
7. **Contact Hub**: Instant clipboard copy for direct email (`feranmiisaac622@gmail.com`) and phone (`+234 702 536 4239`), direct WhatsApp link, and pre-composed email dispatch.
8. **SEO & Structured Data**: Complete Schema.org JSON-LD `Person` metadata for rich Google search indexing and social OpenGraph cards.

## 💻 Local Development

Clone the repository and run the development server:

```bash
# Install dependencies
npm install

# Start Vite dev server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```
